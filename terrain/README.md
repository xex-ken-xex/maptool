# 地形工房

ノードをつないで、陸と海底の高さを多段階で作るシミュレーターです。`index.html` をブラウザで開くだけで動きます（サーバーもビルドも要りません）。

## できること

- ノード式のパイプライン。各ノードは自分のシードを持ち、処理コードを画面で書き換えられます。ノードの追加・削除・つなぎ替えもできます
- 輪になった配線は「循環」として、同じ列で指定回数くり返します（例: 氷床と地殻の沈み込み）
- 無限の平面の世界。同じシードなら、表示する場所や拡大率に関係なく同じ地形になります
- 区画ノード（川と侵食）。世界に固定した 64×64 升目のタイルごとに、窪地を埋める処理（priority flood）、集水面積、ストリームパワー則による侵食、湖を計算します
- 表示: 陰影、等高線・等深線、川、湖、プレート境界、風の帯、神々の照らす円、辺境の霞、ランドマーク
- 出力: 地図 PNG / SVG（レイヤー分け）、標高 CSV / JSON、世界の設定 JSON の保存と読み込み

## 中身の構成

1ファイルにすべて入っています。スクリプト内の印で区切られた部分が、ページと計算用スレッドの両方で使われる共通部分です。

- `/*CORE1*/ … /*END1*/`: 道具箱（ノイズなど）とノードの種類
- `/*CORE2*/ … /*END2*/`: 配線の解析、区画ノード、1地点ごとの計算、行ごとの計算と結果の保持
- 計算は Web Worker で並列に行います（コア数−1、最大8本）。Worker が使えない環境では、ページ内で計算します
