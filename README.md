# maptool

大航海時代（Silver Fall）の地図づくりのための道具をまとめた置き場です。道具ごとにフォルダを分けています。

| フォルダ | 道具 | 内容 |
|---|---|---|
| [terrain/](terrain/) | 地形工房 | ノードをつないで陸と海底の高さを作る、地形生成のシミュレーター |
| [flatmap/](flatmap/) | 平面世界の地図 | 果てしない平面世界を区画のピラミッドで読み、紙の風合いで描く地図描画ソフト。平面・対数極の海図・円盤の全体図 |

## 地形工房 → 平面世界の地図

地形工房の「区画データを書き出す（平面世界の地図用）」は、照らす円と余白を 2.048 km 格子（レベル4の区画の升）で一度だけ計算し、標高（Int16、0.25 m 刻み）・ランドマーク・世界の設定を 1 ファイル（`.zip` の中の `world.sfw`）にまとめます。平面世界の地図の「世界を読み込む」か、地図へのドロップで読み込むと、その格子から区画ピラミッドを作り、川と湖・地名を計算し、ランドマークを地名として描きます。読み込んだ世界はブラウザ（IndexedDB）に残ります。

`.sfw` の形: `"SFW1"` + ヘッダ長（uint32 LE）+ JSON ヘッダ（format, n, C, X0, Y0, litR, pins, world…）+ Int16 n×n の標高（行は北から、X は東、Y は北、m）。
