# maptool

大航海時代（Silver Fall）の地図づくりのための道具をまとめた置き場です。道具ごとにフォルダを分けています。

| フォルダ | 道具 | 内容 |
|---|---|---|
| [terrain/](terrain/) | 地形工房 | ノードをつないで陸と海底の高さを作る、地形生成のシミュレーター |
| [flatmap/](flatmap/) | 平面世界の地図 | 果てしない平面世界を区画のピラミッドで読み、紙の風合いで描く地図描画ソフト。平面・対数極の海図・円盤の全体図 |

## 地形工房 → 平面世界の地図

地形工房の「区画データを書き出す（平面世界の地図用）」は、照らす円と余白を 2.048 km 格子（レベル4の区画の升）で一度だけ計算し、標高（Int16、0.25 m 刻み）・ランドマーク・世界の設定を 1 ファイル（`.zip` の中の `world.sfw`）にまとめます。平面世界の地図の「世界を読み込む」か、地図へのドロップで読み込むと、その格子から区画ピラミッドを作り、川と湖・地名を計算し、ランドマークを地名として描きます。読み込んだ世界はブラウザ（IndexedDB）に残ります。

`.sfw` の形: `"SFW1"` + ヘッダ長（uint32 LE）+ JSON ヘッダ（format, n, C, X0, Y0, litR, pins, world…）+ Int16 n×n の標高（行は北から、X は東、Y は北、m）。

## 平面世界の地図の「立体」

同じ区画キャッシュから WebGL で描く。区画ごとに 64×64 に間引いたメッシュ（海は水面で平ら、縁にスカートで継ぎ目の隙間を隠す）に、平面用に描いた区画の絵をテクスチャとして貼る。まだ無い区画は親の区画の絵と高さで代用し、届いたら差し替える。回転と俯角はこの表示だけ（右ドラッグ・Shift+ドラッグ・二本指、Q/E と R/F）。文字は画面に正立で置き、霧（紙色）の向こうには出さない。カメラ相対の座標で頂点を渡すので辺境でも震えない。

## 平面世界の地図の速さ

- 川と湖の解析は 1 つの worker で約 2 秒（以前は小さな湖を捨てるたびに全升目を走査していて 20 秒以上かかっていた）。
- 区画の標高は、升目より細かいノイズのオクターブを省く（粗いレベルほど速い）。ノイズは 1024×1024 の勾配表を引く方式（旧版と地形は変わる。仮の地形なので支障なし）。
- 区画の絵は 1 コマ約 40 ms まで描き、残りは次のコマで描く。その間は親の絵を拡大して見せる。
- 等高線・等深線・海岸線は 1 回の走査でまとめて抽出し、レベルごとの Path2D を描く。余白（スカート）部分は抽出しない。
- 円盤・海図の表示は、ドラッグやホイール中は半分の解像度で海岸線だけ描き、止まったときに全部描き直す。
- wasm 化はまだ不要と判断。1 区画の標高計算は約 80〜110 ms（92k 点、1 点あたり約 1 µs）で、wasm でも 2 倍程度の見込み。先に効くのは区画数を減らすこと（スカート縮小、IndexedDB キャッシュ）。
